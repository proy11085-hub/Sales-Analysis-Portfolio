\# Dataset



This folder contains the raw and cleaned sales datasets used in this project.



\## Dataset Information

\- Format: CSV / Excel

\- Purpose: Sales performance analysis

\- Used for: SQL, Excel and Power BI analysis



\## Data Fields

\- Order ID

\- Order Date

\- Customer ID

\- Product

\- Category

\- Quantity

\- Unit Price

\- Total Sales

\- Region

\- Payment Method
